# ADR 0001. Хранилище: PostgreSQL

- **Статус:** принято
- **Дата:** 7 октября 2026

## Контекст

Сервис асинхронный (FastAPI), и кроме обработчиков запросов работает фоновый
воркер. Правило «один слот это один гость» должно держаться при одновременных
запросах из разных процессов, а не только в коде одного.

## Решение

Используем PostgreSQL, драйвер `asyncpg`, строка подключения в `DATABASE_URL`.
Схему накатывает Alembic, файла базы в репозитории нет.

Гарантии, ради которых выбран именно PostgreSQL:

- частичный уникальный индекс на активную заявку (ADR 0004);
- `timestamptz` для моментов времени;
- `SKIP LOCKED` при разборе очереди писем в нескольких воркерах.

## Последствия

- **Плюс:** инварианты держит база, а не порядок строк в коде.
- **Минус:** нужен отдельный сервис базы; в разработке это `docker compose`.
- **Минус:** без миграций не обойтись, удалить файл базы нельзя.
