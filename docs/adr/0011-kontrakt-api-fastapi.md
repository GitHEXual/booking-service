# ADR 0011. Контракт API: автодокументация FastAPI

- **Статус:** принято
- **Дата:** 7 октября 2026

## Контекст

Нужно, чтобы описание API не разъезжалось с кодом, и чтобы его можно было прочитать
без запуска приложения.

## Решение

Единственный источник описания это код: маршруты FastAPI и схемы Pydantic.
Отдельного файла контракта, который надо поддерживать вручную, нет.

FastAPI сам собирает OpenAPI. Он доступен по `/openapi.json`, интерактивная
страница по `/docs`. Обращения к сервису видны и проверяются там же.

Тело ошибки у всех обработчиков одинаковое: `{"detail": "текст на русском"}`, где
текст пригоден для показа человеку.

## Последствия

- **Плюс:** нет второго языка описания данных, который надо держать в актуальном
  состоянии.
- **Плюс:** документация всегда есть в запущенном сервисе.
- **Минус:** нет теста на дрейф контракта. Если он понадобится, снимок OpenAPI
  можно закоммитить и сравнивать в CI.
